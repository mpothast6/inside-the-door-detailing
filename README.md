# Inside the Door Detailing

Front-end prototypes for the guest site and the manager site. See `CLAUDE.md` for the full project brief, decisions, and build plan.

## Run locally

    python3 -m http.server -d public 8000

- Guest site: http://localhost:8000/
- Manager site: http://localhost:8000/manager/

## Start in Claude Code

Open this folder in Claude Code. It reads `CLAUDE.md` automatically. A good first message:

> Read CLAUDE.md. Before writing code, propose a simple, low-cost stack and hosting for turning these two prototypes into a real site, and list the decisions you need from me.
